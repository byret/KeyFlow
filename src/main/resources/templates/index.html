Regex examples

\[[^\]]*\]

Matches everything inside square brackets together with the brackets.

\{[^}]*\}

Matches everything inside curly braces together with the braces.

\{\d+\}

Matches placeholders like {0}, {1}, {25}.

\s+

Matches one or more whitespace characters.
